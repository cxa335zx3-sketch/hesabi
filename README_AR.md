# حِسابي — نظام إدارة الأعمال والمحاسبة

هذه نسخة **SaaS جاهزة للتطوير والنشر** وليست مجرد صفحة HTML محلية.

## ما تم إنجازه
- تسجيل وإنشاء حساب لكل منشأة.
- عزل بيانات كل منشأة عن الأخرى.
- قاعدة بيانات SQLite حقيقية.
- جلسات دخول JWT.
- المبيعات والفواتير، المشتريات، المصروفات.
- المنتجات والمخزون وحد إعادة الطلب.
- لوحة مؤشرات وتقارير مختصرة.
- تصميم عربي RTL ومتجاوب للجوال والكمبيوتر.
- API خلفي يمكن ربطه لاحقاً بواجهة دفع واشتراكات.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع.
3. نفّذ: `npm install`
4. ضع قيمة قوية للمتغير `JWT_SECRET`.
5. نفّذ: `npm start`
6. افتح `http://localhost:3000`.

## قبل البيع الفعلي
- نشر الخادم على استضافة سحابية.
- استخدام PostgreSQL في الإنتاج بدلاً من SQLite عند التوسع.
- ربط بوابة دفع بحساب التاجر الخاص بالمالك.
- إضافة نظام اشتراكات وفواتير اشتراك.
- إضافة صلاحيات الموظفين والتدقيق والنسخ الاحتياطي الآلي.
- مراجعة متطلبات الفوترة الإلكترونية والضرائب في الدولة المستهدفة قبل الإعلان عن الامتثال.

> مهم: لا تضع مفاتيح الدفع أو أسرار JWT داخل ملفات الواجهة أو المستودع العام.
